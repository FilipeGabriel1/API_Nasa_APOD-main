Aglomerados de galáxias (resumo)

O que são
- Estruturas com dezenas a milhares de galáxias ligadas gravitacionalmente.

Conteúdo
- Galáxias + gás quente (emite em raios X) + matéria escura (dominante na massa).

Por que importam
- Servem para estudar evolução de galáxias e cosmologia (massa total, crescimento de estruturas).
