Buracos negros estelares (resumo)

O que são
- Regiões onde a gravidade é tão intensa que existe um horizonte de eventos.

Formação
- Podem se formar a partir do colapso de estrelas muito massivas.

Observação indireta
- Discos de acreção, emissão em raios X, efeitos em estrelas companheiras e ondas gravitacionais.
