Cinturões e reservatórios de corpos gelados (resumo)

Cinturão de asteroides
- Região entre Marte e Júpiter com muitos corpos pequenos.

Cinturão de Kuiper (KBO)
- Região além de Netuno com objetos gelados; inclui muitos transnetunianos.

Nuvem de Oort (hipótese)
- Reservatório muito distante de cometas de longo período.

Importância
- Preservam pistas sobre a formação inicial do Sistema Solar.
