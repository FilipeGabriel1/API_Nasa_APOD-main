Matéria escura (resumo)

O problema
- Observações indicam mais gravidade do que a matéria visível explica (curvas de rotação, lentes, aglomerados).

O que pode ser
- Um componente não luminoso que interage pouco com luz; a natureza exata ainda é tema de pesquisa.

Evidências comuns
- Velocidade de estrelas em galáxias, dinâmica de aglomerados, lentes gravitacionais.
