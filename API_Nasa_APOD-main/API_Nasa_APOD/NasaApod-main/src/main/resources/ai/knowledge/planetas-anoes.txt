Planetas anões (resumo)

Definição (ideia geral)
- Corpos que orbitam o Sol e têm forma aproximadamente esférica, mas não “limparam” a vizinhança orbital.

Exemplos
- Plutão e outros objetos transnetunianos.
- Ceres no cinturão de asteroides.

Importância
- Ajudam a entender a formação e evolução do Sistema Solar.
