Evolução estelar (resumo)

Fator principal
- A massa inicial determina quase todo o “destino” de uma estrela.

Sequência principal
- Longa fase de fusão de hidrogênio.

Fases finais
- Estrelas leves: gigantes vermelhas → nebulosa planetária → anã branca.
- Estrelas massivas: supergigantes → supernova → estrela de nêutrons ou buraco negro.
