Proteção planetária (resumo)

Objetivo
- Evitar contaminação biológica entre corpos celestes (ida e volta de amostras).

Por que importa
- Protege possíveis ecossistemas e a integridade científica das buscas por vida.

Práticas
- Esterilização, controle de biocarga, trajetórias planejadas e protocolos de amostras.
