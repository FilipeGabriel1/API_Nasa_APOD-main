Missões históricas (resumo)

Por que importar
- Missões antigas criaram padrões de engenharia, ciência e operação usados até hoje.

Categorias
- Exploração lunar/planetária, telescópios espaciais, sondas interestelares e observatórios solares.

Lição geral
- Grandes avanços vêm de objetivos claros, instrumentação adequada e coleta/arquivamento de dados.
