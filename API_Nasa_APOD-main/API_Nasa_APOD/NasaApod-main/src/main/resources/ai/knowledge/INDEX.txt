Objetivo
Este índice lista tópicos de astronomia/ciência espacial que você pode cobrir na base de conhecimento.

Como usar (RAG)
- Crie/edite arquivos .txt nesta pasta.
- Cada arquivo deve conter explicações curtas, exemplos e definições.
- Prefira parágrafos curtos e listas.
- Se você quiser que a IA NÃO invente: no .env use AI_CHAT_KNOWLEDGE_STRICT=true.
