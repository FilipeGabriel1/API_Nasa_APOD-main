Luas (satélites naturais) (resumo)

Variedade
- Existem luas rochosas, geladas e com atividade geológica.

Efeitos de maré
- Forças de maré podem aquecer o interior e gerar vulcanismo/atividade.

Atmosferas e oceanos
- Algumas luas podem ter atmosfera tênue ou oceanos subsuperficiais.

Relevância
- São alvos importantes na busca por ambientes potencialmente habitáveis.
