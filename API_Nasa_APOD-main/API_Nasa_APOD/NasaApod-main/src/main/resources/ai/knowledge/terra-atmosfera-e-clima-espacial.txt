Terra, atmosfera e clima espacial (resumo)

Atmosfera
- Camadas (de baixo para cima): troposfera, estratosfera, mesosfera, termosfera.

Clima espacial
- Termo para condições do ambiente espacial (vento solar, tempestades geomagnéticas).

Impactos
- Pode afetar satélites, navegação, redes elétricas e comunicações.
