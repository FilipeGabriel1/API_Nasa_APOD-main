Estrelas de nêutrons e pulsares (resumo)

Estrela de nêutrons
- Objeto compacto resultante de certas supernovas; densidade extrema.

Pulsar
- Estrela de nêutrons rotativa com feixes de radiação; observada como pulsos regulares.

Aplicações
- Relógios naturais e laboratórios para física de alta densidade.
